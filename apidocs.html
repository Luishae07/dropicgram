API Reference

REST API for Dropicgram — a social photo-sharing platform. Auth is via JWT in the `Authorization: Bearer <token>` header (or a `token` cookie). All endpoints return JSON. — 1.0.0

⬇️ Download openapi.json

auth

POST/api/auth/login
Log in
POST/api/auth/logout
Log out
GET/api/auth/me
Get the current user
POST/api/auth/register
Register a new account

posts

POST/api/posts
Create a post (text, image, or both)
GET/api/posts/explore
All posts, newest first
GET/api/posts/feed
Feed of posts from people you follow + your own
POST/api/posts/polls/{pollId}/vote
Vote on a poll
GET/api/posts/user/{username}
A user's profile + posts
GET/api/posts/{id}
Get a single post
PUT/api/posts/{id}
Edit own post
DELETE/api/posts/{id}
Delete own post
POST/api/posts/{id}/comments
Comment or reply (optionally with an image)
POST/api/posts/{id}/like
Like a post
POST/api/posts/{id}/pin
Pin/unpin own post
POST/api/posts/{id}/quote
Quote a post with your own text
POST/api/posts/{id}/react
Add an emoji reaction
POST/api/posts/{id}/repost
Repost a post
POST/api/posts/{id}/unlike
Unlike a post

users

POST/api/users/requests/{username}/accept
Accept a follow request
POST/api/users/requests/{username}/decline
Decline a follow request
GET/api/users/{username}
Get a user profile with counts
POST/api/users/{username}/follow
Follow a user (or request to follow if private)
POST/api/users/{username}/unfollow
Unfollow a user

account

DELETE/api/account/account
Permanently delete account
PUT/api/account/avatar
Upload avatar image
PUT/api/account/cover
Upload cover image
PUT/api/account/password
Change password
PUT/api/account/privacy
Toggle private account
PUT/api/account/profile
Edit display name + bio
GET/api/account/settings
Get notification/dark-mode settings
PUT/api/account/settings
Update settings

search

GET/api/search
Search users, posts, and hashtags
GET/api/search/followers/{username}
Followers of a user
GET/api/search/following/{username}
Users a person follows
GET/api/search/hashtag/{tag}
Posts with a hashtag
GET/api/search/requests
Pending follow requests for you
GET/api/search/suggestions
Suggested users to follow
GET/api/search/trending
Trending hashtags by usage

notifications

GET/api/notifications
List notifications + unread count
POST/api/notifications/read-all
Mark all notifications read
GET/api/notifications/unread
Unread notification count

messages

GET/api/messages/conversations
List DM conversations
GET/api/messages/{username}
Message thread with a user (marks read)
POST/api/messages/{username}
Send a message (text or photo)

stories

GET/api/stories
Stories from you + people you follow (24h)
POST/api/stories
Post a story image
POST/api/stories/{id}/view
Mark a story viewed

misc

GET/api/misc/blocks
Blocked users
POST/api/misc/blocks/{username}
Block a user
DELETE/api/misc/blocks/{username}
Unblock a user
GET/api/misc/bookmarks
Saved posts
POST/api/misc/bookmarks/{postId}
Save a post
DELETE/api/misc/bookmarks/{postId}
Unsave a post
GET/api/misc/drafts
List drafts
POST/api/misc/drafts
Save a draft
DELETE/api/misc/drafts/{id}
Delete a draft
GET/api/misc/export
Download your data as JSON
GET/api/misc/muted-words
Muted words
POST/api/misc/muted-words
Add a muted word
DELETE/api/misc/muted-words
Remove a muted word
GET/api/misc/mutes
Muted users
POST/api/misc/mutes/{username}
Mute a user
DELETE/api/misc/mutes/{username}
Unmute a user
POST/api/misc/reports
Report content
GET/api/misc/stats
Your account stats
GET/ws
WebSocket endpoint for real-time events (DMs, notifications, typing, read receipts)
