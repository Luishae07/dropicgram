API Reference

API for Dropicgram, a social photo-sharing platform. Share moments, discover people, and keep your images protected with a custom .pqos format (invisible watermarking + perceptual duplicate detection). All endpoints return JSON. Authenticate with `Authorization: Bearer <JWT>`.

⬇️ Download openapi.json
