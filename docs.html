Dropicgram Documentation

A social photo-sharing platform with a custom .pqos image format, real-time messaging, and full REST + WebSocket APIs.

Quick Start

  1. Create an account via POST /api/auth/register — you get back a JWT.
  2. Send it as Authorization: Bearer <token> on every request.
  3. Post text or images to POST /api/posts.
  4. For real-time events, open a WebSocket to /ws?token=<JWT>.

Authentication

All endpoints except register and login require a Bearer token. Registering or logging in also sets an httpOnly cookie as a fallback.

curl -X POST https://api/api/auth/login \ -H "Content-Type: application/json" \ -d '{"username":"you","password":"pass"}'

Images & the .pqos format

Uploaded images are converted to .pqos: a container holding a PQOS magic header, owner id, timestamp, sha256, an invisible XOR-obfuscated watermark, and a WebP payload. Images are served back as image/webp.

  • Watermark — each image is cryptographically tied to its uploader.
  • Dedup — exact SHA-256 match plus a perceptual pHash catch re-encoded, resized, and rotated copies. Duplicates are rejected with a 409 naming the original owner.
  • Compact — images are capped at 1600px, auto-rotated, and recompressed to WebP.
